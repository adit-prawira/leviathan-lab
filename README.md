# Leviathan Lab

3D sea monster designer. Built with Rust + Bevy.

Design, sculpt, paint, and animate custom sea monsters. A fun project to learn Rust through gamedev.

## Quick Start

```bash
cargo run
```

Requires Rust 1.80+.

See [plan.md](plan.md) for the full roadmap.

7 phases. Each phase ships something you can launch and play with.
